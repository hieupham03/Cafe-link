# CafeLink - Hồ sơ báo cáo học phần

Báo cáo Word/PDF và hồ sơ nộp môn học được nhóm bàn giao riêng. Repository cung cấp mã nguồn, test, script và tài liệu kỹ thuật để build, chạy và kiểm chứng ứng dụng.

| Nội dung về dự án | Tài liệu |

| Phạm vi, người sử dụng, nghiệp vụ | [Đặc tả](../cafelink-system/docs/PROJECT_SPECIFICATION.md) |
| Thành phần và xử lý mạng | [Kiến trúc](../cafelink-system/docs/ARCHITECTURE.md), [giao thức](../cafelink-system/docs/PROTOCOL.md) |
| Đóng góp về phục hồi | [Cơ chế phục hồi](../cafelink-system/docs/RECOVERY.md) |
| Chạy trình bày | [Runbook](../cafelink-system/docs/RUNBOOK.md) |
| Kiểm thử và đánh giá | [Kiểm thử](../cafelink-system/docs/TESTING.md), [thực nghiệm](../cafelink-system/docs/EXPERIMENTS.md) |

Kết quả tự động gắn với commit và artifact của từng lượt [GitHub Actions](https://github.com/hieupham03/Cafe-link/actions). Kết quả đo do công cụ sinh ra được lưu ngoài source; khi trình bày số liệu cần giữ cùng cấu hình, manifest và raw của lượt đo.
